# IMI共通語彙基盤 住所型

「住所型」(Address) は、IMI共通語彙基盤コア語彙（バージョン2.4.2）で定義される、**住所を表現するためのクラス用語**。識別子は `ic:住所型`。上位型は `ic:事物型`（さらに上位は `ic:概念型`）。

住所の構成要素（都道府県・市区町村・町名・丁目・番地・号・方書 等）をそれぞれ独立したプロパティ用語として持つ。本コア語彙には独立した「郡」プロパティは定義されていない（郡は「市区町村」「町名」等の表記に含めて記述する想定）。

| ic:都道府県コード | ic:コード型 | 0..1 | 都道府県のコードを記述するためのプロパティ用語 |

## 番地補足について

`ic:番地補足`（xsd:string, 0..1）は、**番地の前の、「東」「北」「浜」「甲」「イ」などの文字を記述するためのプロパティ用語**。番地（`ic:番地`「番、街区の表記」）とは別フィールドとして、番地の前に付く方位・字（あざ）相当の文字を保持する。ABR解説書が「番地補足」の根拠として参照しているのはこの定義である。

## 継承される共通プロパティ

住所型は事物型を継承するため、以下の共通プロパティも持つ。

| 識別子 | 値型 | 回数 | 説明 |
|---|---|---|---|
| ic:種別 | xsd:string | 0..n | 種別の表記を記述するためのプロパティ用語 |
| ic:種別コード | ic:コード型 | 0..n | 種別コードを記述するためのプロパティ用語 |
| ic:メタデータ | ic:文書型 | 0..n | データのメタデータを記述するためのプロパティ用語 |
| ic:説明 | xsd:string | 0..n | 説明を記述するためのプロパティ用語 |
| ic:ID | ic:ID型 | 0..n | 事物に割り振られたID（識別子)を記述するためのプロパティ用語 |
| ic:表記 | xsd:string | 0..n | 文字列による表記を記述するためのプロパティ用語 |
| ic:参照 | ic:参照型 | 0..n | 追加情報などを参照するURLを記述するためのプロパティ用語 |
| ic:画像 | xsd:anyURI | 0..n | 画像を参照するURLを記述するためのプロパティ用語 |
| ic:記述 | ic:記述型 | 0..n | 種別付きの説明文を記述するためのプロパティ用語 |
