# 国立印刷局が取り組むデータ整備（ベース・レジストリ運用業務）

> 独立行政法人国立印刷局 玉木浩貴（IPA未来会議資料）。スライド資料をMarkdown化（図は要約補記）。

― ベース・レジストリ運用業務について

## 国立印刷局の概要

- 設立：独立行政法人として平成15年4月設立（起源は明治4年創設の大蔵省紙幣司）
- 職員数：3,995名（R7.4.1現在）（男性 約74％／女性 約26%）
- 役職員の身分：国家公務員
- 組織：本局、研究所、全国に6工場

独立行政法人国立印刷局は国の行政事務と密接に関連した事務・事業を、国の相当な関与の下に、正確・確実に執行することが求められている。

## 国立印刷局の主な業務内容

国民生活に密着した公共性の高い製品や情報サービスを社会に提供。

- 日本銀行券、旅券、切手等の製造
- 官報の編集・印刷・配信
- 偽造防止技術等の調査・研究
- 令和７年４月～ ベース・レジストリ※運用業務の追加
  - ※制度横断的に多数の手続で参照されるデータからなるデータベース（例：住所・所在地、法人の名称など）

## 1 ベース・レジストリの整備と運用

### 社会全体のデジタル化の推進

社会の基盤となるデータ群の整備・利活用が不可欠。行政府によるベース・レジストリの整備（公的基礎情報データベース）と、情報連携やデータ利活用を推進するためのルール・仕組みの整備。

### ベース・レジストリの整備・利用促進に向けた法整備

デジタル社会形成基本法等の一部改正法案（R6.5成立）

1. データの品質確保（デジタル社会形成基本法）: ベース・レジストリのデータ品質の確保のための措置を講ずる旨を規定。
2. 国によるデータベースの整備やデータ連携の促進（デジタル手続法）: 国の行政機関等は、ベース・レジストリの整備等に関し、国立印刷局及び情報処理推進機構に対し、必要な協力を求めることができる旨を規定。
3. データベースやシステムの整備を効果的に行うための体制強化（独立行政法人国立印刷局法ほか）: 国立印刷局の目的・業務に、ベース・レジストリを構成するデータの加工、記録、保存及び提供を行うことを追加。関係業務の主務大臣に内閣総理大臣（デジタル大臣）を追加。

### ベース・レジストリの整備等の業務フロー

| 工程 | 内容 | 担当 |
|---|---|---|
| 設計 | データベースの設計 | 国の行政機関（デジタル庁）等 |
| 開発 | システムの開発・改修 | 国の行政機関（デジタル庁）等 |
| 収集 | 関係機関に対するデータの提供依頼／データの収受 | 国立印刷局（委託を受けて実施） |
| 加工 | 誤記の補正・形式統合・標準文字への変換等 | 国立印刷局（委託を受けて実施） |
| 記録・保存 | データベースへのデータの記録・保存 | 国立印刷局（委託を受けて実施） |
| 提供 | データを利用可能な形で提供（API、ダウンロードサイト掲載等） | 国立印刷局（委託を受けて実施） |

### ベース・レジストリの運用における国立印刷局の役割

運用プロセス：データ受領 → データの加工・記録・保存 → 公開 → データ提供・利活用。官報発行プロセスで培った情報管理のノウハウを活用（発行前は公開前情報の秘密管理・指定期日に確実に公開、発行後は正確な情報の公開・プライバシー配慮）。

### 整備・運用のスケジュール

- ユースケースや費用対効果を考慮し、法人・不動産・アドレスを注力領域として指定。
- 公的基礎情報データベース整備改善計画（R7.6閣議決定）に基づき整備・改善や利用を促進。

| BRの種類 | 内容 | 時期 |
|---|---|---|
| アドレス | 町字データ整備／提供 | R6～ |
| アドレス | 国立印刷局による運用 | データ更新を実施しながら運用 |
| 法人 | システム整備／サービス提供 | ～R7／順次 |
| 法人 | 国立印刷局による運用 | R8～ |

## 2 アドレス・ベース・レジストリの運用業務

### 日本の住所・所在地（アドレス）に関する制度の現状

住居表示実施地域の例：東京都／千代田区／霞が関二丁目／１番／６号

- 町字：地方自治法に基づき市区町村が新設・変更・廃止
- 街区符号・住居番号：住居表示法に基づき市区町村が付番

住居表示未実施地域の例：石川県／加賀市／大聖寺南町ニ／４１番地

- 町字：地方自治法に基づき市区町村が新設・更新・廃止
- 地番：不動産登記法に基づき法務局が付番

行政が一元的に管理する仕組みがなく、様々な主体が個別に整理。結果として表記揺れ等が発生し、データ連携を阻害する要因に。

### Coffee Break：アドレス表記の2つの制度

同一地点「千葉県浦安市舞浜2-11」の2制度での表記：

- 住居表示実施地域：千葉県／浦安市／舞浜2丁目／11番
- 住居表示未実施地域：千葉県／浦安市／舞浜／2番地11

### アドレス・ベース・レジストリの概要

- 情報参照元：市区町村（町字の新設・変更・廃止、街区符号・住居番号の付番）／法務局（地番の付番）
- アドレスBR（デジタル庁が整備）：町字を識別するコードとして町字IDを付与
- 利用者：行政機関（自治体情報システム標準化のデータ要件として「町字ID」の設定を規定）／民間事業者／個人

現状：令和６年度にデジタル庁が「町字」までのマスターデータ整備を実施。街区符号・住居番号、地番のデータ整備については整備方針を検討中。

### 国立印刷局によるアドレス・ベース・レジストリの運用

国立印刷局が運用業務を実施（R7.4～）。デジタル庁が整備したアドレスBRの町字データに対し、正確性・最新性を継続的に確保していくための「更新プロセス」の運用を担当。

- 加工：登録データの加工・確認
- 記録・保存：システムの運用・保守
- 提供：データ提供・利用者対応（行政機関・民間事業者等へ情報提供）

### 町字の新設・更新・廃止等の手続の概要

町字の新設・更新・廃止等の手続（区域の変更を含む）は地方自治法第260条に規定。

1. 町字の新設・変更・廃止の計画（事由の例：区画整理事業の実施、住居表示の実施、住民からの要望 等）
2. 市区町村議会の議決
3. 市区町村からの告示の発出 → 告示の情報を基に登録データを加工（正確性の確保）
4. 施行（効力発生）→ 施行期日に町字データを提供（最新性の確保）

### 事例①：正確性の確保

- 事由：住居表示の実施／施行期日（効力発生日）：令和7年11月1日
- ＜変更前＞廃止される町字：山田北町1丁目、山田北町2丁目、矢田町1丁目 等
- ＜変更後＞新設される町字：山田五丁目（ヤマダ5チョウメ）
- 市区町村からの回答例：追加は「山田五丁目」のみ／「山田北町」は全域廃止／「矢田町」「山田町」は字が一部残るため廃止しない／「山田西町」は2丁目が残るため廃止しない。
- 提供された告示資料だけでは正確なデータ加工ができない場合があり、市区町村との連絡調整による意思疎通が重要。

### 事例②：最新性の確保

最新データの提供 → 町字変更の告示の施行期日に遅滞なく更新する必要。

- 告示の事例①：「この告示は、公布の日から効力を生ずる」→ 確認時点ですでに効力が発生。
- 告示の事例②：「換地処分の公告があった日の翌日から（中略）変更する」→ 告示の時点では効力発生日が未確定。
- ポイント：告示資料のみで施行期日を把握するには限界があり、事前に把握・確認するための市区町村との連絡調整が不可欠。

### アドレス・ベース・レジストリに関する今後の展開

- 郵便番号との紐づけ対応：行政機関の申請フォームにおいて、郵便番号の入力により町字を自動表示。
- 住所・所在地情報管理システム（共通化候補）：パイロットシステムを開発（R8年度）、業務検証を実施予定（R9年度～）。

## 3 法人ベース・レジストリの運用業務

### 法人ベース・レジストリ整備の背景

現状（整備前）：法務省（法務局）が登記事項証明書を発行 → 申請者が請求・取得し手続書類とともに提出 → 行政機関が突合確認・公用請求。国民・行政機関の双方に多大な手間・事務負担。

### 法人ベース・レジストリの概要

法人BR（デジタル庁が整備中）：法務省の登記情報システム → 縮退・正規化ツール → データベースシステム → 情報連携システム → 行政機関がオンライン確認。令和8年度サービス開始。

効果：申請者による登記事項証明書の取得が不要（添付書面の省略）、行政機関の公用請求での取得も不要。

### 国立印刷局による法人ベース・レジストリの運用

国立印刷局が運用業務を実施（R8.4～）。加工（縮退・正規化ツール）／記録・保存（DBシステム運用保守）／提供（情報連携システム、アカウント管理・問合せ対応・利用促進）。

### 法人ベース・レジストリに関する今後の展開

行政機関：申請フォームでの法人情報の自動入力、変更届出の省略（ワンスオンリー）、突合確認・審査等の事務負担軽減。民間利用は横断的課題として検討中。

## 4 まとめ

- 令和7年度から、国立印刷局の新たな目的・業務に「ベース・レジストリを構成するデータの加工、記録、保存及び提供」が加わり、社会の基盤となるデータ群の整備・利活用を担う役割が強化された。
- 国立印刷局は、ベース・レジストリの運用実務の担い手として、デジタル庁をはじめとする関係機関と連携しつつ、アドレス・法人のBR運用業務を確実に遂行し、信頼性の高いデータ基盤の安定的な提供を支える。
- 政府情報のデータ品質の確保・向上に取り組んできたノウハウ・実績を活かし、デジタル社会の実現に向けた政府施策に引き続き貢献していく。
