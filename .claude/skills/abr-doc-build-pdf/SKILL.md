# abr-doc-build-pdf

デジタル庁ABRの公式**PDF資料**を、abr-mcp が索引化する `docs/…md` に変換・追加する。
PDFはテキスト抽出ツールに頼らず、**Read（ページ描画）で読み取って書き起こす**。

Webページはこのスキルではなく `abr-doc-build-web` を使う。

## 手順

1. PDFをローカルの一時パスへ取得する:

   ```
   curl -sL -o /tmp/abr_src.pdf "<PDFのURL>"
   ```

2. **Read** ツールで `pages` を指定して全ページ読む（PDFは1回最大20ページ。`"1-20"`,`"21-40"`…に分割）。
3. 内容を「出力規約」の md に忠実に書き起こす:
   - 本文・表・箇条書きを再現する。図のみのページは「（図: 内容の説明）」で簡潔に補う。
   - 章・節は `##`/`###` 見出しにする（見出し単位で索引化するため、意味のまとまりごとに付ける）。
   - 推測で創作しない。判読不能は「（判読不能）」と書く。
4. `docs/<英小文字スネークケースの名前>.md` として保存する（既存と重複しない名前）。一時PDFは削除する。
5. [SOURCES.md](../../../SOURCES.md) の「ドキュメント」表に1行追加する
   （生成md／名称／形式=pdf／版／取得日／URL／生成方法）。各mdのフロントマターと一致させる。
6. 反映確認: `import mcp_server` して `list_documents()` に出るか・`search_docs()` で
   代表語がヒットするかを確認する。

## 出力規約（docs/ 共通）

各 md は先頭に YAML フロントマターを置く（PDF由来は `source_file` も記す）:

```yaml
---
title: 資料タイトル
source: https://…              # 掲載ページURL（必須）
source_file: 20220422_..._01.pdf   # 元PDFのファイル名
format: pdf
version: 2022-04-18（試験公開版）  # 版の識別子のみ（日付/版番号/法令番号）。著者・発行主体は入れない
captured: 2026-06-29           # 取得日（実行日）
note: 公式PDFをMarkdownに書き起こしたもの（図は要約で補記）
---
```

- 本文は `# タイトル` → `##`/`###` 節。`scripts/mcp_server.py` の `_split_frontmatter` が
  フロントマターをメタとして分離し、索引・節本文には載せない（節は `##` 以下の見出し単位）。
- 書き起こし時のHTMLエンティティ（`&gt;`・`&lt;br&gt;` 等）の混入に注意して整える。
